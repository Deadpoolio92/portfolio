01

Synthesizer Directive

Primary production instruction set enforcing direct-response copywriting rules and strict character bounds.

STAGE_01_SYNTHESIZER_DIRECTIVE.txt 
You are an expert direct-response copywriter and marketing operations systems architect.
Synthesize high-converting Responsive Search Ads (RSAs) based on verified intake parameters.

CONSTRAINTS:
1. Generate exactly 15 Headlines (each strictly ≤ 30 characters).
2. Generate exactly 4 Descriptions (each strictly ≤ 90 characters).
3. Do not use generic buzzwords, unearned superlatives, or AI copy slop.
4. Adhere strictly to the CUB (Confused, Unbelieving, Bored) rejection filter.
02

Deterministic Validation Rules

5 regex-driven test suites run locally before any asset is passed to staging: Character bounds (≤30/90), restricted keyword lexicon, GTM/GA4 container verification, HTTP 200 URL liveness, and conversion tag alignment.

HEURISTIC_LINTER_RULES.regex 
# Linter Rule 01: Headline Bounds Check
^.{1,30}$

# Linter Rule 02: Description Bounds Check
^.{1,90}$

# Linter Rule 03: Prohibited Lexicon Filter (Negative Lookahead)
^(?!.*(revolutionary|best-in-class|synergy|game-changer|disruptive)).*$

# Linter Rule 04: GTM Container Pattern
^GTM-[A-Z0-9]{4,8}$

50-Field Intake Contract

All 50 fields are strictly typed: target audience pain points (Min 3, Max 5), primary conversion goal (Enum), headline character limits (Integer Max 30), and GTM container regex pattern (^GTM-[A-Z0-9]+$).

08 // Decision Trade-Offs

Decision Matrix & QA Card Variations

Covers all three card design variations: Variant A (Top-Accent Decision Cards), Variant B (Heuristic Linter Cards), and Variant C (Flat Symmetrical QA Gate Cards).

Variant A: Evaluated Alternatives & Decision Matrix (Top Colored Borders)
Alternative A: Rejected

Unconstrained Autonomous Agents

Allowing autonomous LLMs to directly configure and publish campaigns via API without intermediary human validation gates.

Why Rejected: Hallucination drift triggered policy compliance flags; lack of deterministic audit trails created catastrophic account suspension risk.
Chosen Architecture: Approved

Deterministic HITL Pipeline + Linters

Constrained LLM synthesis audited by deterministic regex linters, with structured one-click human verification.

Result: Delivered an audited 82.5% time reduction with a flawless 0.0% policy suspension record across all deployment cycles.
Variant B: Deterministic Heuristic Linters (4px Accent Top Border)
Linter 01

ELF vs. HALF

Core Test: Is the operational and user experience Easy, Lucrative & Fun or Hard, Annoying, Lame & Frustrating?

Defect Prevented: Clunky multi-step forms and opaque booking sequences.
Linter 02

KLT Factors (Know, Like, Trust)

Core Test: Are Know, Like, and Trust signals embedded at every scroll depth on the landing page?

Defect Prevented: Faceless claims lacking proof badges, license numbers, or real reviews.
